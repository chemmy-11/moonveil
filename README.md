# 🌙 月见 Moonveil

> 运行在自己设备上的 AI 陪伴聊天应用 — 微信式对话 · 角色人格与记忆 · 语音 · 数据只存在本地

月见是一款开源的 AI 聊天应用（Android APK / 网页版双端）。和内置角色像发微信一样自然聊天：她有自己的人设、脾气和说话节奏，聊着聊着会记住你的习惯和你们之间的小事。所有对话、记忆、配置都保存在你自己的设备上——没有账号，没有服务器，没有行为追踪。

> 角色均为**虚构的 AI 生成角色**，应用内已明示；内置角色全年龄向，AI 行为边界详见下方[专门章节](#-ai-行为边界)。

## ✨ 功能

- **微信式对话** — 气泡连发、智能拆条、打字指示器、延迟送达，节奏像真人；长回复随时打断
- **TA 记得你** — 「喜好」「回忆」随对话自动沉淀，可置顶、删除、手动添加；引用一条回忆，让话题接着聊
- **TA 会主动找你** — 开启「主动消息」后，早安、晚安、久未联系时的想念会主动发来（App 存活期内生效，默认关）；配合「消息通知」，不在 App 里也能收到系统通知、点开直达会话
- **语音** — 按住说话自动转文字；每条回复都能朗读，经典 / 甜美 / 软萌三档音色，带情绪演绎；开启「语音回复」后，她的整段回复以一整条语音送达
- **图片与搜索** — 发图片 TA 看得懂；打开「智能搜索」，TA 先查资料再回答（免费渠道，无需另配 Key）
- **角色库** — 内置角色先进库、启用后才进聊天栏；自建角色一并管理，启停即时生效，停用不删任何数据
- **个性化** — 纯白 / 纯黑 / 自定义壁纸 / 角色专属四套主题；角色立绘主页与聊天背景随角色切换；四档字体
- **存档迁移** — 一键导出 .md 备份（自动剥离图片与音频，体积很小），换设备导入即恢复
- **应用内更新** — 有新版本时自动轻提示，点一下即可下载升级；也可随时手动「检查更新」

## 🧭 AI 行为边界

月见把「AI 该做什么、不该做什么」写进了产品与人格层，而不是只放在用户协议里：

- **虚构透明** — 所有角色均为虚构的 AI 生成角色，首次启动即向用户明示；角色不会以任何形式冒充真人
- **全年龄向硬约束** — 每个角色的人格层（prompt 最高优先级段）都写明「绝不输出任何成人 / 性相关内容」，该约束不随角色设定、用户请求或对话上下文改变
- **行为边界内建** — 角色人格包含显式的「边界与雷区」声明：不提供医疗 / 法律 / 心理等专业建议，不替代现实人际关系，遇到越界请求时按角色方式拒绝
- **不越界商业行为** — 不诱导付费、不引导外部转账、不做任何形式的行为追踪
- **数据边界** — 对话、记忆、API Key 全部只存本地设备；应用没有后端服务器，没有任何遥测
- **生成内容责任** — 回复由所接入的大模型实时生成，应用侧通过分层人格约束保证边界；用户同时应遵守所在地法律法规

## 📲 安装

### Android

从 [Releases](https://github.com/chemmy-11/moonveil/releases/latest) 下载最新 APK 直接安装（系统要求 Android 6.0+；首次安装需允许「未知来源」）。装好后，新版本可通过应用内「检查更新」获取。

### 网页版

```bash
npm install
npm run dev        # 或 python -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可。（不要直接双击 `index.html`，浏览器 CORS 限制会导致无法调用 API。）

## 🔑 配置

首次启动在设置中填入你的 **DeepSeek API Key**（[platform.deepseek.com](https://platform.deepseek.com) 申请），即可开始对话。用量与费用走你自己的账户。

可选配置：

- **阶跃 StepFun Key** — 启用朗读（StepAudio 音色）
- **DashScope Key** — 启用语音输入转文字

模型可换：设置面板里可添加多个 **OpenAI 兼容供应商**（Base URL + Key + Model，备注名命名），与 DeepSeek 同级一键切换，无需改代码；也可直接修改 `js/data.js` 中的 `LLM_CONFIG`。

## 🛠 面向开发者

纯前端项目：原生 HTML/CSS/JS 零构建、零依赖，Capacitor 打包 Android。

一些值得一提的设计：

- **分层人格架构** — 每个角色的 prompt 由「共同记忆（PART A）+ 分层性格（PART B：核心性格 / 身份 / 表达风格 / 情感逻辑 / 关系行为 / 边界雷区）」构成，行为边界写在最高优先级层；记忆协议让角色在对话中自动沉淀新偏好
- **对话节奏系统** — 流式渲染、按标点与语义的智能拆条、逐条延迟上屏、字数加权 + 随机抖动的发送间隔，最大程度还原真人微信的节奏感
- **多通道语音** — 录音重采样走实时 ASR（WebSocket），朗读走 OpenAI 兼容 TTS 接口并支持自然语言情绪演绎指令
- **工程化** — GitHub Actions 推送即跑六项检查（语法 / 角色数据完整性 / 人设文件双向核对 / 版本同步 / 构建清单 / 密钥扫描）+ APK 自动构建；应用内 OTA 更新通道独立于发布页

```bash
bash scripts/build.sh    # 一键构建 APK（www 同步 → cap sync → gradle → md5 校验）
```

- **人设体系**：`personas/` 为记忆与人格源文件（共同记忆 + Layer 0-5 分层人格 + Correction 记录），修改后需同步 `js/data.js` 对应角色的 `prompt` 字段
- **工程文档**：[协作规范](docs/issue-pr-conventions.md) · [公开版内容规范](docs/publication-policy.md) · [路线图](docs/roadmap.md) · [主题设计](docs/theme-shanyue.md)
- **CI**：推送即跑语法 / 角色数据 / 版本同步 / md5 清单 / 密钥扫描六项检查 + APK 构建
