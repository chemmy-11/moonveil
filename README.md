# 🌙 月见 Moonveil

> 运行在自己设备上的 AI 陪伴聊天应用 — 微信式对话 · 数据只存在本地 · 自备 DeepSeek API Key

月见是一款开源的 AI 聊天应用（Android APK / 网页版双端）。和内置角色像发微信一样自然聊天：她有自己的人设、脾气和说话节奏，聊着聊着会记住你的习惯和你们之间的小事。所有对话、记忆、配置都保存在你自己的设备上，没有账号，没有服务器。

## 👩 内置角色

| 角色 | 类型 | MBTI | 简介 |
|------|------|------|------|
| **苏晚晚** | 温柔治愈 | ISFP | 花店店主，轻声细语，记得你说过的每一件小事 |
| **唐苓** | 元气活泼 | ESFJ | 烘焙学徒，话痨 + emoji 轰炸，直球表达喜欢 |
| **季萤** | 慢热治愈 | INFP | 中文系大二 · 深夜电台主播，慢热但内心住着一片星海 |

不合口味？用「创建角色」向导几分钟捏一个自己的。

## ✨ 功能

- **微信式对话** — 气泡连发、智能拆条、打字指示器、延迟送达，节奏像真人；长回复随时打断
- **她记得你** — 「她的喜好」「我们的回忆」随对话自动沉淀，可置顶、删除、手动添加；引用一条回忆，让话题接着聊
- **语音** — 按住说话自动转文字；她的每条回复都能朗读，经典 / 甜美 / 软萌三档音色，带情绪演绎
- **图片与搜索** — 发图片她看得懂；打开「智能搜索」，她先查资料再回答（免费渠道，无需另配 Key）
- **个性化** — 纯白 / 纯黑 / 自定义壁纸三主题；角色专属立绘主页与聊天背景；四档字体
- **存档迁移** — 一键导出 .md 备份（自动剥离图片与音频，体积很小），换设备导入即恢复
- **应用内更新** — 「检查更新」一键下载升级，无需重新安装

## 📲 安装

### Android

从 [Releases](https://github.com/chemmy-11/moonveil/releases/latest) 下载最新 APK 直接安装（系统要求 Android 6.0+；首次安装需允许「未知来源」）。装好后，新版本可通过应用内「检查更新」获取。

### 网页版

```bash
npm install
npm run dev        # 或 python -m http.server 8080
```

浏览器打开 `http://localhost:8080` 即可。（不要直接双击 `index.html`，浏览器 CORS 限制会导致无法调用 API。）

## 🔑 配置

首次启动在设置中填入你的 **DeepSeek API Key**（[platform.deepseek.com](https://platform.deepseek.com) 申请），即可开始对话。用量与费用走你自己的账户。

可选配置：

- **阶跃 StepFun Key** — 启用朗读（StepAudio 音色）
- **DashScope Key** — 启用语音输入转文字

模型可换：修改 `js/data.js` 中的 `LLM_CONFIG`，支持任何 OpenAI 兼容 API。

## 🔒 隐私与内容

- 聊天记录、记忆、API Key 全部只存在你的设备本地，应用没有任何后端服务器
- 内置角色为全年龄向，不会输出成人内容
- 快照与存档保存在设备上，导出文件请自行妥善保管

## 🛠 面向开发者

纯前端项目：原生 HTML/CSS/JS 零构建、零依赖，Capacitor 打包 Android。

```bash
bash scripts/build.sh    # 一键构建 APK（www 同步 → cap sync → gradle → md5 校验）
```

- **人设体系**：`personas/` 为记忆与人格源文件（共同记忆 + Layer 0-5 分层人格 + Correction 记录），修改后需同步 `js/data.js` 对应角色的 `prompt` 字段
- **工程文档**：[协作规范](docs/issue-pr-conventions.md) · [公开版内容规范](docs/publication-policy.md) · [路线图](docs/roadmap.md) · [主题设计](docs/theme-shanyue.md)
- **CI**：推送即跑语法 / 角色数据 / 版本同步 / md5 清单 / 密钥扫描六项检查 + APK 构建
